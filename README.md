# 財政部公務人員協會：官網＋會務管理系統

一套給「財政部公務人員協會」用的工具，分兩部分：

| 部分 | 給誰用 | 形式 |
|------|--------|------|
| **官網** | 會員、同仁、外界 | 靜態網站（無後端），可放內網網站或任何靜態主機 |
| **會務管理系統** | 協會幹部（理事長、秘書長、會計、承辦） | **單一離線 HTML**，內網 Edge 直接開；資料存在共用資料夾裡的一個資料檔 |

兩者用「官網資料檔」串起來：幹部在會務系統編最新消息、活動、福利 → 一鍵「發布到官網」輸出資料檔 → 官網讀它顯示。官網的入會申請、活動報名產生「申請資料檔」→ 會務系統匯入。

> 開發規則（離線、資安、命名、版號）看 [CLAUDE.md](CLAUDE.md)。

## 一、會務管理系統（`會務系統/會務管理系統.html`）

### 資料怎麼存
- 第一次開：選「協會資料夾」（共用磁碟上的一個資料夾，用 `showDirectoryPicker`），系統在裡面讀寫：
  - `協會資料.json`：所有資料（每筆紀錄有 `id`、`建立時間`、`修改時間`、`修改人`）
  - `附件/`：公文、表單、會議紀錄的附件原檔
  - `備份/`：每次存檔前自動備份，保留最近 30 份
- **多人同時用**：存檔前比對檔案修改時間，若別人存過，先重新讀入、以「每筆紀錄的修改時間」合併，真的衝突（同一筆兩邊都改）跳出對照讓人選。
- 不支援資料夾 API 的瀏覽器：退回「開啟資料檔／下載資料檔」。
- 選用：資料檔加密（通關密語 → PBKDF2 → AES-GCM，用瀏覽器內建 `crypto.subtle`）。
- 個資只收必要欄位（不收身分證字號）；畫面提醒「資料夾權限請由資訊單位設定」。

### 登入與角色
- 選自己的名字＋密碼（PBKDF2 雜湊存在資料檔）。角色：理事長、常務理事、理事、監事、秘書長、會計、承辦人、一般會員（唯讀）。
- 角色只決定介面能做什麼、簽核由誰簽；**不是真正的資安控管**（說明裡要講清楚）。

### 模組

| # | 模組 | 內容 |
|---|------|------|
| 1 | **首頁** | 待我簽核、待催繳會費、近期活動與會議、本月收支、會員數變化 |
| 2 | **會員名冊** | 基本資料（姓名、服務機關、單位、職稱、公務電話、Email、入會日期、會員類別、會籍狀態）；標籤（例：新進、理監事、志工）；多條件查詢；入會／退會／轉調**異動歷程**；分眾名單（匯出 Outlook 收件者字串、CSV 合併列印）；Excel／CSV／ODS 匯入（欄位對應、重複比對） |
| 3 | **活動報名** | 建立活動（名額、候補、截止日、費用）；報名名單（手動、匯入官網報名檔）；**簽到**（勾選或輸入員工編號）；出席率統計；通知名單（未報名、未簽到）；活動照片／成果紀錄 |
| 4 | **會費與帳務** | 會費標準（入會費、常年會費）；年度逐人收繳、**催繳名單**、收據列印；收支記帳（會計科目表可自訂、傳票號自動編）；預算編列與執行率；報表：收支預算表、收支決算表、現金出納表、資產負債表、財產目錄、基金收支表（**格式依主管機關財務處理規定，實作前先查證**）；匯出 Excel／CSV |
| 5 | **公文與簽核** | 收文／發文登記（文號、來文機關、主旨、期限、承辦人、附件）；簽核流程（承辦 → 秘書長 → 理事長，可在設定改）；退回、加簽、意見；**進度追蹤與逾期提醒**；簽核時間統計 |
| 6 | **申請表單** | 表單設計器（文字、日期、單選、多選、金額、附件、簽名欄）；內建範本：入會申請書、退會申請書、會員福利申請（婚喪喜慶、生育、住院慰問）、建議案提案單、活動報名表；填寫 → 送簽 → 核定 → 歸檔；可列印成紙本格式 |
| 7 | **會議與決議** | 會員（代表）大會、理事會、監事會：開會通知、議程、簽到（自動判斷出席是否過半）、決議事項、**決議追蹤**（交辦誰、何時完成）、會議紀錄 |
| 8 | **建議與協商案** | 公務人員協會特有：依《公務人員協會法》向機關提出的**建議案**、**協商案**（條次與可提事項實作前到全國法規資料庫查證）；案件登記、提案人、送出日期、機關回復、協商紀錄、結果；成果可發布到官網「權益專區」 |
| 9 | **文件知識庫** | 章程、法規、會議紀錄、範本、常見問答；分類、標籤、全文搜尋、版本（舊版保留可看） |
| 10 | **官網發布** | 編輯最新消息、活動公告、會員福利（特約商店）、權益成果、下載檔、常見問答、協會簡介與組織；按「發布到官網」輸出 `官網/資料/site-data.js`（或下載後手動放） |
| 11 | **設定** | 協會基本資料、服務機關／單位清單、會員類別、會費標準、會計科目、簽核流程、使用者與角色、資料檔加密、備份份數 |

服務機關清單預設放財政部本部與所屬機關（國庫署、賦稅署、關務署、國有財產署、財政資訊中心、各區國稅局…），**實作前查證最新組織**，設定裡可增刪。

### 共通功能
- 全部列表：排序、篩選、搜尋、分頁、勾選批次動作、匯出 CSV／Excel。
- 列印：收據、通知單、簽到表、名冊、報表都有列印版（A4 直式，標楷體可選）。
- 每個畫面右上角「說明」，講這頁怎麼用。
- 操作紀錄：誰在何時改了什麼（存在資料檔）。

## 二、官網（`官網/`）

| 頁面 | 內容 |
|------|------|
| 首頁 | 協會標語、最新消息 5 則、近期活動、快速連結（入會、福利、權益、下載） |
| 關於協會 | 宗旨、沿革、組織架構圖、理監事名單（範例資料）、章程 |
| 最新消息 | 列表＋分類＋內文頁 |
| 活動 | 近期／過去活動、報名（產生報名資料檔）、活動成果 |
| 會員福利 | 福利項目、申請方式、特約商店 |
| 權益專區 | 建議與協商成果、相關法規連結 |
| 入會申請 | 線上填寫 → 產生**可列印申請書**＋**申請資料檔**（交給協會，由會務系統匯入） |
| 下載專區 | 表單、章程、會議紀錄 |
| 常見問答 | 可展開問答 |
| 聯絡我們 | 協會地址、電話、Email（範例資料） |

- 靜態網站、無後端，所有內容來自 `官網/資料/site-data.js`（會務系統產生）；改內容不用改程式。
- 手機版版面要正常（16px 邊距、不左右捲）。
- 也要能以 file:// 直接開（內網沒有網站伺服器時）。
- 不放追蹤碼、不載入外部字型或 CDN。

## 會員專區（線上系統，v1.2 起）
會員與幹部可從網路登入：`官網/portal/`（官網選單「會員專區」），資料存在 Supabase，權限由資料庫列層級安全控管。
設定步驟見 [線上系統/設定說明.md](線上系統/設定說明.md)，資料庫結構見 `線上系統/資料庫結構.sql`。
離線版會務管理系統照常可用（收據列印、收支記帳、決算報表目前只在離線版）。

## 四、怎麼開始（第一階段 v1.0）

1. 用 Edge 開 `會務系統/會務管理系統.html`，按「選擇協會資料夾」。
   - 想先練習：選 `會務系統/範例協會資料夾`（**全部是虛構範例資料**），登入任一範例帳號，密碼皆為 `demo1234`：
     林嘉文（理事長）、陳怡君（秘書長）、黃志明（會計）、張雅婷（承辦人）、李建宏（監事）、吳佩珊（一般會員）。
   - 正式使用：選共用磁碟上的空資料夾，系統會引導建立協會資料與第一位管理者。
2. 官網：直接開 `官網/index.html`（file:// 可用），或把 `官網/` 整個放到靜態網站主機。內容在會務系統「官網發布 → 發布」更新。
3. 範例資料重新產生：`node 製作/範例資料.mjs`（會覆蓋範例協會資料夾與 `官網/資料/`）。

### 實作前查證紀錄（2026-10）
- 《公務人員協會法》第 6 條（建議事項）、第 7 條（協商事項與不得協商事項）、第 27 條（經費來源）：依全國法規資料庫（pcode=S0010008）條文整理於官網「權益專區」。
- 財務報表：銓敘部《公務人員協會財務處理作業規定》（100.6.3 部管二字第 1003385050 號）第六點，會計報告為收支決算表、現金出納表、資產負債表、財產目錄；格式見其附件一、會計科目見附件二（資產、負債、基金暨餘絀、收入、支出）。v1.0 的收支決算表採「決算數／預算數／比較增減／說明」欄位；**附件原檔未能從開發環境下載，正式報送前請以附件格式核對**，預設會計科目可在「設定」調整。
- 服務機關預設清單：依《財政部組織法》第 5 條所列次級機關（國庫署、賦稅署、各地區國稅局、關務署、國有財產署、財政資訊中心）＋部本部、財政人員訓練所；組織若有調整，請在「設定 → 基本清單」增刪。
